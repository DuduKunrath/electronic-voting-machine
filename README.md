# 🗳️ Simulador de Urna Eletrônica

Este projeto é um simulador de urna eletrônica desenvolvido com **HTML, CSS e JavaScript**, com foco em reproduzir a lógica básica de votação e a interação do usuário com a interface.

O desenvolvimento foi realizado como parte de estudos práticos, em conjunto com conteúdos do curso da **B7Web**, com algumas adaptações e ajustes próprios durante a implementação.

---

## 🚀 Funcionalidades

* Inserção de votos via interface (cliques com o mouse)
* Exibição dinâmica dos candidatos
* Voto em branco
* Confirmação e correção de voto
* Validação de etapas da votação

---

## 🛠️ Tecnologias utilizadas

* HTML5
* CSS3
* JavaScript (Vanilla JS)

---

## 🎯 Objetivo do projeto

O principal objetivo foi praticar:

* Manipulação de DOM
* Lógica de programação em JavaScript
* Estruturação de interfaces interativas
* Organização de código frontend

---

## 📚 Observações

Este projeto foi desenvolvido para fins de estudo e prática.
Parte da base foi construída acompanhando as aulas da **B7Web**, servindo como reforço prático dos conceitos apresentados.
